Este proyecto tiene como objetivo desplegar una infraestructura completa para una aplicación multicapa. La infraestructura incluye un router con tres redes (DMZ, Intranet y NAT) y varios servidores: un servidor web, un servidor SSH, un servidor de bases de datos MySQL, un servidor DHCP, un servidor DNS y un servidor FTP. Además, se deben desplegar dos equipos cliente: uno con Windows y otro con Linux.
El servidor de bases de datos debe importar un archivo CSV con el listado de equipamientos educativos de la ciudad de Barcelona, obtenido del portal OpenData Barcelona. Posteriormente, se debe crear una pequeña aplicación que muestre el contenido de las tablas cargadas en la base de datos.
El proyecto se organiza en tres sprints de dos semanas (10 horas cada uno) y toda la configuración y documentación debe mantenerse en un repositorio GitHub, utilizando validación mediante clave pública/privada. En el repositorio también debe documentarse el uso de Git (add, commit, push, pull, clone) y organizarse toda la documentación en formato Markdown. Todos los sistemas y servicios deben incluir el usuario bchecker con la contraseña bchecker121.
